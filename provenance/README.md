# Provenance hashes

These files are SHA-256 integrity fingerprints of the repository tree as of commit `cdb8eb9`
(the files were renamed afterwards; the recorded hashes refer to the original paths). They let anyone
check that a file is byte-identical to the archived version. They are **not** a certificate of
mathematical correctness, peer review, or acceptance by any body. Correctness evidence is the Lean
build plus the axiom report in `AXIOMS.md`, reproduced by CI.
